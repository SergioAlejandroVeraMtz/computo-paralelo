# Cómputo paralelo: hilos, multiprocesamiento y taxonomía de Flynn

Notebooks de la unidad de aprendizaje Cómputo Paralelo, Ingeniería en Inteligencia Artificial, ESCOM-IPN.

## Contenido

- **`comparacion_hilos_gil_colab.ipynb`**: compara el tiempo de ejecución de tareas con hilos y con procesos en Python, mostrando el efecto del GIL en tareas de cálculo intensivo. Está preparado para Google Colab.
- **`comparacion_hilos_multiprocesamiento.ipynb`**: compara hilos y multiprocesamiento y muestra el PID y el núcleo de CPU que reporta cada cálculo.
- **`taxonomia_flynn.ipynb`**: clasificación de arquitecturas de computadoras con la taxonomía de Flynn (SISD, SIMD, MISD y MIMD).

## Ejecución

Abre cada notebook en Google Colab desde **Archivo > Subir notebook** y ejecuta las celdas en orden.
